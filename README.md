## 📖 About The Project

**BookNook** is a small online library management platform designed for book lovers. It allows users to explore a collection of books, add their own books, borrow books for a limited period, and manage their borrowed books.

The goal of BookNook is to make book discovery and borrowing simple, convenient, and enjoyable through a clean and user-friendly interface.

**Add a book, borrow a book, return a book.**

## ✨ Key Features

- **User Authentication:** Secure user registration and login system.
- **Explore Books:** Browse and discover books from the library.
- **Add New Books:** Authenticated users can add new books to the collection.
- **My Books:** Manage books added by the logged-in user.
- **Borrow Books:** Borrow available books for 7 days.
- **My Borrows:** View and manage borrowed books.
- **Return Books:** Return borrowed books and keep the library updated.
- **Book Details:** View detailed information about individual books.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Loading Skeletons:** Smooth loading experience while data is being fetched.
- **Category-Based Collection:** Explore books by different categories.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Folder

```bash
cd booknook
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env.local` file in the frontend root directory and add your required environment variables.

Example:

```env
BETTER_AUTH_SECRET=your_secret_key
BETTER_AUTH_URL=http://localhost:3000
MONGODB_URL=your_mongodb_connection_string
```

Add any additional variables required by your actual project configuration.

### 5. Run the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## ⚙️ Backend Setup

The backend is built with Express.js and MongoDB.

### 1. Navigate to the Backend Folder

```bash
cd backend
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Configure Environment Variables

Create a `.env` file in the backend directory.

```env
MONGODB_URL=your_mongodb_connection_string
PORT=8000
```

### 4. Start the Backend Server

```bash
npm run dev
```

The backend server will run at:

```text
http://localhost:8000
```

*Note: Adjust folder names, scripts, and environment variable names according to your actual project configuration.*
